# Andrea Marrano

**Software engineer · Milano** — I build web products for a living and small open source tools
because I enjoy it, and I write about what I learn along the way.

For the past five-plus years I've been building web products from end to end: the backend that
holds the data, the frontend people actually use, the integrations in between. Today I work on
high-traffic automotive sites, where most of my days are about keeping things fast and reliable,
understanding why a system behaves the way it does, and fixing it properly when it doesn't.

I'm just getting started in open source. The idea is simple: build tools that solve a real
problem for someone, and become a better programmer by doing it in public, where other people can
read the code, question my choices and show me what I missed.

- 🔭 **Currently building:** [Reader Mode AI](https://github.com/marrano92/reader-mode-ai) —
  a browser extension for reading articles without distractions, with translation in place
- ⚡ I like problems where the answer is a tool people can actually use
- 🤝 Open to collaborate: if one of my tools helps you, or you see a better way to do something,
  I'd love to hear it

## What I write about

- **Stories from production.** When something breaks I follow the thread all the way back: what
  the symptom looked like, which hypotheses I tested, what the real cause was and what I'd check
  sooner next time. The reasoning is usually more useful than the fix.
- **Working with AI coding agents.** They are part of my daily routine, and they work best inside
  a disciplined process: a clear spec, small steps, tests before any claim of success,
  documentation kept next to the code.
- **Small tools that remove friction**, and what building them taught me.

Latest: [Building a Safari-style Reader Mode as a Chrome Extension (MV3) with DeepL Translation](articles/2026-10-reader-mode-chrome-extension.md)

## How I work

- Small slices, tests before claims, everything documented in the repo: if it is not verified,
  it is not done
- Open source as a way to learn in public and help other developers

My languages are mostly PHP, JavaScript and Python, but I care more about the problem than about
the stack.
